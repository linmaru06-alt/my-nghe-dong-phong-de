# Tự động đặt tên Commit Git

Khi làm việc trong dự án này, nếu người dùng yêu cầu push code hoặc có các thay đổi cần lưu trữ, AI Agent cần:
1. Tự động viết mô tả commit (commit message) dựa trên những thay đổi thực tế đã thực hiện.
2. Không cần hỏi lại người dùng về nội dung commit message để tiết kiệm thời gian.
3. Khuyến khích sử dụng chuẩn Conventional Commits (ví dụ: `feat:`, `fix:`, `style:`, `refactor:`, `chore:`).
